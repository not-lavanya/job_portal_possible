# Version 1: Reuse your application profile

**One job:** Help a student apply to another role without starting over. The prototype is a browser-only demo with fictional data; it does not submit applications.

## Screens
- **Home:** Show the saved profile and a second role ready to apply to.
- **Profile:** Review or edit reusable contact, education, experience, and skills.
- **Role details:** Show the sample role and start its application.
- **Application review:** Show the role's form with saved profile details already filled in; let the student review before stopping.

## Main flow
1. Open Home and choose the second sample role.
2. Review or edit the saved profile.
3. Start the application and see matching details filled in.
4. Review the filled application. No real submission occurs.

## Sample data
Use a fictional student, **Alex Morgan**, with sample contact details, education, one experience entry, and skills. Show two fictional regional internship roles; the student has already applied to one and is starting the other. Mark all details as prototype data.

## Out of scope today
Question explanations, application status or rejection feedback, recruiter tools, AI-written answers, real employer portals, accounts, backend, integrations, and actual application submission.
