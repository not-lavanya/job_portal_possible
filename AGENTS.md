# Who we are
Team of 4 building an AI-powered job application platform for college students and regional recruiters.

# The project
Two-sided platform addressing the structural design of job application portals. System A: centralized tracker + calendar + AI agent + autofill for applicants. System B: standardized templates + rejection feedback for recruiters. Starting regionally (e.g., Granville/Columbus, Ohio).

# How we work
Interview-driven PRD development. Capture research as markdown with dates. Use AI coding tools (Claude Code, Codex, Cursor). Narrow scope in Thursday's sprint. Mark gaps [OPEN].
